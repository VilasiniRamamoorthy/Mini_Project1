# Mini_Project1
TMDB GUVI Mini Project - 1 - TMDB Movie Data Analysis

Project Overview: This project analyses TMDB movie data using Python, Pandas, SQL, data visualization and machine learning.

Project Structure:
01_Data_Cleaning.ipynb – Data cleaning and preprocessing.
02_SQL_Analysis.ipynb – SQL queries and database analysis.
03_EDA_Visualization.ipynb – Exploratory data analysis and visualizations.
04_Machine_Learning.ipynb – Machine learning models and predictions.

data/ – Six source CSV files and the SQL database file.

Technologies Used:
Python
Pandas
Matplotlib
Seaborn
Plotly
SQL
Google Colab
GitHub

How to Run: Clone or download this GitHub repository.

Open the notebooks using Google Colab.
Ensure the data/ folder is available.
Run the notebooks in the recommended sequence.
Install the required Python libraries using requirements.txt.

Data Source- TMDB movie dataset.
